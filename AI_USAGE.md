# AI Usage

I used ChatGPT and Claude throughout this assignment.

ChatGPT was used to draft an initial implementation specification: architecture, state ownership, API surface, and UX behaviour. Claude was then used to review that specification against the assignment text and to write the implementation. The review was useful — it caught a missing `title` field, a hedge on the saved-screen filters, and a weak choice around holding editable state in the query cache, all of which I changed before any code was written.

I made the final calls on every decision in `DECISIONS.md`, including the ones where I overrode what the AI proposed. I read every line of the submitted code and can explain and defend it.
